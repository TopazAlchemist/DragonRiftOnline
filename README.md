## Boss Strategy Database

### DragonLord Valtheros (Lvl 80)
- **HP**: 45,000,000
- **Phase 1**: Fire breath + Wing slam
- **Phase 2**: Minion spawn + Shadow breath
- **Phase 3**: Enrage at 20% HP
- **Recommended DPS**: 15,000+
- **Strategy**: Kill adds first, stack fire resist potions

### Queen Seraphina (Lvl 75)
- **HP**: 32,000,000
- **Mechanics**: Shield phases every 25%
- **Strategy**: Interrupt casting, range DPS uptime

## Class Build Guides

### Fire Mage — Burst DPS
```
Stats Priority: INT > CRIT > HASTE > MASTERY
Talents: Inferno 3 / Arcane Focus 2 / Temporal Shift 1
Rotation: Fireball → Pyroblast → Combustion → repeat
```

### Holy Paladin — Tank/Healer Hybrid
```
Stats Priority: STAMINA > ARMOR > INT > SPIRIT
Talents: Divine Shield 2 / Light's Grace 3 / Holy Shock 2
Rotation: Flash Heal → Holy Shock → Holy Light → Shield
```
